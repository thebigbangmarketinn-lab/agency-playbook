# Customer Acquisition System — Agency Playbook

A complete, ready-to-deploy system for a performance + social marketing agency to differentiate from competitors and reprice from commodity ad management to a premium customer-acquisition service.

**Core idea:** Stop selling "ad management." Sell a *customer-acquisition system* — paid social ads + sub-60-second WhatsApp follow-up + closed-loop cost-per-customer reporting. It's the gap almost no agency at the SMB tier fills, and it justifies 2x+ higher retainers.

## How to use it

1. Read `03` first for the strategy and pricing.
2. Set up `01` + `02` (use the `04` diagram as the build spec) on your **best client** as a 30-day proof.
3. Use the results to reprice with the script in `03`, then roll out to all clients.
4. Send the `05` report every month.
